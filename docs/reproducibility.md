# Reproducibility Guide

## Dataset: This dataset is a recoded version of the publicly available data from P&eacute;rez-Chada et al. ("Screen use, sleep duration, daytime somnolence, and academic performance in school-aged adolescents", Mendeley Data / PLOS ONE). It includes 1,257 adole

---

## 1. Requirements

- Web browser or data analysis software (R, Python, Excel)
- No special software required for basic data access

## 2. Data Access

```
# Clone repository
git clone https://github.com/juanmoisesd/adolescentes-argentina-uso-de-redes-sociales-sueno-y-somnolencia-base-recodifica.git
cd adolescentes-argentina-uso-de-redes-sociales-sueno-y-somnolencia-base-recodifica
```

## 3. Data Format

- Data is provided in standard CSV/HTML format
- UTF-8 encoding
- See `data_dictionary.csv` or README for variable descriptions
