# Incident Response Plan

## 1. Identification
Detect unauthorized changes to the dataset or metadata.

## 2. Containment
Restrict write access to the repository if a breach is suspected.

## 3. Eradication
Revert to the last known good state using Git history and verified backups.

## 4. Recovery
Verify integrity with checksums and restore public access.

## 5. Lessons Learned
Conduct a post-mortem to prevent future incidents.
