# Abstract

This dataset provides a recoded and processed version of the original research by Pérez-Chada et al. regarding screen use, sleep duration, daytime somnolence, and academic performance in Argentine adolescents. The original study covered 1,257 school-aged adolescents. This recoded database facilitates subsequent analysis by standardizing variables and cleaning records for immediate use in data science tools. The findings highlight the interconnection between digital habits and physiological well-being in the youth population.
