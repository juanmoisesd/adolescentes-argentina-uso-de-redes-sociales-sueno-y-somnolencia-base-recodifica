# Contributing to Adolescentes Argentina Research

We welcome contributions!

## How to Contribute
1. **Report Bugs**: Use GitHub Issues.
2. **Improve Documentation**: Submit Pull Requests for typos or clearer explanations.
3. **Data Quality**: Report any anomalies found in the dataset.
4. **Code**: Suggestions for better ETL or analysis scripts are welcome.

## Submission Process
- Fork the repo.
- Create a feature branch.
- Submit a PR with a clear description of changes.
