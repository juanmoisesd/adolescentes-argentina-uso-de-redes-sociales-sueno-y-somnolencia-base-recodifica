# Codebook

## Dataset: Adolescentes Argentina Uso De Redes Sociales Sueno Y Somnolencia Base Recodifica

### Variables

| Variable | Description | Type | Units/Labels |
|----------|-------------|------|--------------|
| id | Unique identifier for each participant | string | N/A |
| country | Country of the study (Argentina) | string | N/A |
| year | Year of data collection | integer | Years |
| value | Recoded metric value | number | Variable dependent |
| unit | Unit of measurement for the value | string | e.g., hours, scores |
| source | Source of the original data point | string | Mendeley Data |
| notes | Qualitative notes on the record | string | N/A |

### Methodology
Data was recoded from the original Mendeley Data repository. Negative values were handled as missing, and categories were standardized for cross-sectional analysis.
