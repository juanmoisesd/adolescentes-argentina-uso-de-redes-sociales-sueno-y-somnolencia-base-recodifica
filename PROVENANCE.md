# Provenance

## Data Origin
The data in this repository was derived from the Mendeley Data publication:
*   **Original Title**: Screen use, sleep duration, daytime somnolence, and academic performance in school-aged adolescents.
*   **Original Authors**: Pérez-Chada et al.
*   **Original DOI**: 10.17632/v6m6j8z9y2.1

## Processing Steps
1. **Extraction**: Downloaded original CSV/Excel files.
2. **Cleaning**: Handled missing values and outliers.
3. **Recoding**: Transformed categorical variables into standardized formats.
4. **Validation**: Verified data integrity against schema.
