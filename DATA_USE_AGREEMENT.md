# Data Use Agreement

This agreement governs the use of the "Adolescentes Argentina Uso De Redes Sociales Sueno Y Somnolencia Base Recodifica" dataset.

1. **Permitted Use**: The data may be used for research, educational, and analytical purposes.
2. **Attribution**: Users must provide proper citation as specified in `CITATION.cff`.
3. **No Redistribution**: Users should not redistribute the raw data; instead, point others to this repository.
4. **Ethical Compliance**: Users must adhere to the ethics guidelines outlined in `ETHICS.md`.
