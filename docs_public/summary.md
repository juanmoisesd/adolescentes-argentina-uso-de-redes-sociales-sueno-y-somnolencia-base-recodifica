## What is this dataset?

This dataset is a recoded version of the publicly available data from P&eacute;rez-Chada et al. ("Screen use, sleep duration, daytime somnolence, and academic performance in school-aged adolescents", Mendeley Data / PLOS ONE). It includes 1,257 adole

## Why does it matter?

This dataset contributes to open science by making research data freely available for reuse, analysis, and citation.

## Who can use it?

- Researchers and academics
- Policy makers
- Journalists and science communicators
- Students and educators
- General public

## How to use it?

1. Download the data from [GitHub](https://github.com/juanmoisesd/adolescentes-argentina-uso-de-redes-sociales-sueno-y-somnolencia-base-recodifica)
2. Open with Excel, R, Python or any data analysis tool
3. Cite using the CITATION.cff or CITATION.bib files
